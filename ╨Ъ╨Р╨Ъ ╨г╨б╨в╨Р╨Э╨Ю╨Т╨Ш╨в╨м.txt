Калькулятор «Бронирование стёкол» как приложение

1. Загрузите ВСЕ файлы из этой папки (не саму папку) на любой сайт с https, например GitHub Pages:
   - на свой сайт в отдельную папку, например allinvrn.ru/calc/
   - или бесплатно: зайдите на app.netlify.com/drop и перетащите туда папку целиком,
     через минуту будет ссылка вида https://....netlify.app

2. Откройте эту ссылку:
   - Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на гл. экран»
   - iPhone (Safari): «Поделиться» → «На экран Домой»
   - Компьютер (Chrome / Edge / Яндекс): значок установки в адресной строке
     или меню → «Установить приложение»

3. Приложение работает и без интернета после первого открытия.

Важно: сохранённые объекты, материалы и заказ-наряды хранятся на каждом устройстве
отдельно. С телефона на компьютер они сами не переносятся.

Обновление: замените index.html на сайте новым файлом и в sw.js поменяйте
VERSION (например film-calc-v2), чтобы приложения подтянули новую версию.
